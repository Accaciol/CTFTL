## 🚀 Como Estudar e Utilizar este Projeto

1. **Revisão Teórica Ativa**: Acesse os resumos na pasta `capitulos/` para dominar os conceitos chave exigidos em cada capítulo do Syllabus v4.0.
2. **Consulta a Materiais de Apoio**: Utilize os manuais e exames oficiais em `materiais/` para aprofundar tópicos específicos.
3. **Prática Prática (Simulador & Flashcards)**:
   - Abra o arquivo [app/index.html](file:///home/accacio/Documents/Study/CTFTL/app/index.html) diretamente no seu navegador.
   - Selecione entre o **Simulado Completo** (40 questões cronometradas) ou o **Simulado por Capítulo**.
   - Pratique com os **21 Flashcards** integrados no app para fixar definições e termos técnicos.

## 🎯 Dicas de Ouro para a Prova CTFL v4.0

* **Whole-Team & Shift-Left**: A prova v4.0 dá forte ênfase à cultura ágil, integração contínua e testes iniciados antes do código.
* **Técnicas de Caixa-Preta (Capítulo 4)**: Pratique exaustivamente a Análise de Valor Limite (AVL de 2 e 3 valores), Partição de Equivalência (PE) e Tabelas de Decisão ($2^N$ regras).
* **Cobertura Caixa-Branca**: Lembre-se que **100% de Cobertura de Decisão garante 100% de Cobertura de Sentença**, mas o inverso não é verdadeiro.
* **K-Levels (K1, K2, K3)**: Questões de nível K3 exigem cálculo e aplicação prática dos conceitos.
